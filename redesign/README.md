# Дивеевский паломник — редизайн

Эта версия опубликована отдельно от исходной:

- исходный вид: `https://makariy1997.github.io/diveevskii_palomnik/`
- редизайн: `https://makariy1997.github.io/diveevskii_palomnik/redesign/`

Исходная страница сайта остаётся в корне репозитория. Редизайн использует те же тексты, фотографии и бронирование, а стили и анимации находятся в этой папке.

Скрипт `scripts/optimize_images.py` создаёт локальные AVIF, WebP и LQIP-файлы в `img/optimized/`. GitHub Actions запускает его после изменения скрипта и добавляет сгенерированные файлы в репозиторий.
